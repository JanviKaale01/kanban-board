# 📋 Kanban Board
A simple Kanban Board application built using HTML, CSS and JavaScript to manage tasks efficiently.

## ✨ Features
- Add new tasks with a title and description.
- Delete tasks.
- Drag and drop tasks between columns.
- Three task columns: To Do, In Progress and Done.
- Automatic task count updates.
- LocalStorage to save tasks even after refreshing the page.

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript
- LocalStorage API

## 🚀 How to Run
1. Clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` using Live Server.
